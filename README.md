🏏 IPL Analysis Dashboard (2008–2024)
Power BI | Data Modelling | DAX | Data Visualization








📌 Project Overview

This repository contains an end-to-end IPL Analysis Dashboard built using Power BI, showcasing insights from IPL seasons 2008 to 2024.
The dashboard highlights team performance, player statistics, match outcomes, and key KPIs using advanced data modelling and DAX calculations.

This project is ideal for:

Data Analyst portfolio

Power BI learning

Sports analytics demonstration

🎯 Business Requirements Covered

The dashboard answers major IPL insights including:

🏆 Tournament Winner each year

🔢 Total Runs, Wickets, Sixes & Fours

⭐ Most Player of the Match Winner

🟧 Orange Cap Holder (Most Runs)

🟪 Purple Cap Holder (Most Wickets)

👤 Batsman & Bowler Stats with Filters

🎲 Winning % Based on Toss Decision

🏅 Top 5 Batsmen & Top 5 Bowlers

🏆 Top Winning Teams

🎖️ Top 10 Most Player of the Match Award Winners
